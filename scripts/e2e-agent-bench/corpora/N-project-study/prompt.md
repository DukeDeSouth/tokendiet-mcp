Изучи проект в директории `{workspace}` и дай структурированный отчёт.

Отчёт должен содержать:
1. **Назначение проекта** — что делает TokenDiet MCP
2. **Стек** — язык, runtime, ключевые зависимости
3. **Архитектура** — основные модули (`src/pipeline`, `src/tools`, …)
4. **Entry points** — как запускается MCP-сервер
5. **Инструменты MCP** — перечисли все tools и их роль
6. **Токенайзер** — какой encoding используется для подсчёта
7. **Верификатор** — как работает rollback при неудачном сжатии
8. **Тесты** — как запустить, сколько тестов
9. **Dogfood benchmarks** — что измеряют
10. **Ограничения** — известные лимиты (AST языки, schema budget, …)

Формат: markdown, конкретные пути к файлам, без общих фраз.
